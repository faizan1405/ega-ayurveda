# EGA Ayurveda — Ancient Ayurvedic Wisdom. Refined for Modern Wellness.

> **Client Presentation Demo**: A modern, botanical luxury e-commerce experience for EGA Ayurveda, an Indian Ayurvedic wellness brand.

Designed to transcend conventional herbal websites by adopting an **Aesop / premium luxury wellness aesthetic** — combining authentic classical Ayurvedic scripture with contemporary minimalism, slow organic motion, and responsive performance.

## ✨ Interactive Highlights

- **Dynamic Frosted Header**: Transparent on hero, smoothly transitions to frosted ivory blur on scroll.
- **Interactive Botanical Parallax**: Floating saffron and amla markers with gentle organic physics.
- **Hero Product Storytelling**: Asymmetrical editorial breakdown with interactive ingredient tabs and Dinacharya morning ritual guides.
- **Gold & Silver Rasashastra Orbs**: Interactive solar (*Swarna*) and lunar (*Rajata*) alchemy showcase on deep forest-green.
- **Interactive Botanical Monograph**: From Nature to Ritual circular cards featuring Sanskrit names, *Dravya Guna*, taste (*Rasa*), and *Dosha* affinities.
- **Targeted Wellness Paths**: Curated journeys for Digestion, Detox, Skin Radiance, Ojas Longevity, and Mind Balance.
- **Vaidya Consultation Booking**: Live appointment scheduling modal with certified Ayurvedic doctors for Video/WhatsApp sessions.
- **Prakriti / Dosha Diagnostic Tool**: 3-step constitution quiz calculating Vata, Pitta, or Kapha dominance with direct formulation matching.
- **Slide-Out Cart & Free Shipping Tracker**: Real-time bag drawer with quantity controls, coupons (`AYURVEDA10`, `SWARNA20`), and demo checkout flow with celebratory confetti.
- **Full Product Detail Page**: High-resolution gallery with thumbnail switcher, accordions, Charaka Samhita citations, verified customer reviews, and **Sticky Mobile Add to Cart**.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite 8
- **Styling**: Tailwind CSS v4 with custom serif editorial typography (*Cormorant Garamond*, *Cinzel*, *Plus Jakarta Sans*)
- **Icons**: Lucide Icons
- **Animation**: CSS Keyframes + Canvas Confetti
- **Deployment**: GitHub Pages (Vite build + GitHub Actions)

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/faizan1405/ega-ayurveda.git
cd ega-ayurveda

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
